FPGA RC car: SPI, XADC & PWM interface

A two-Basys3 control system recovered from the original EE102 project report. The handheld unit samples two analog joysticks, sends an 8-bit command through an NRF24L01 link, and the vehicle converts the received command into five PWM outputs.

Executive summary

what was built

Problem

Turn two-axis analog joystick movement into wireless steering and throttle commands for a four-wheel-drive vehicle using FPGA logic at both ends.

Implementation

XADC capture, 8-bit command encoding, SPI radio controllers, payload checking, and PWM generation are separated into remote, shared, and vehicle VHDL compile sets.

Recorded result

The project is not fully functional in its recovered form. The existing source passes VHDL-2008 syntax analysis only; the report supplies the physical-build evidence and demonstration.

Implementation flow

end-to-end control path
  1. Sample the joysticks.The handheld Basys3 alternates VAUX6 and VAUX14 through XADC and reduces each converter value to six control bits.
  2. Encode the command.REMOTE_UNIT converts steering or throttle movement into the 8-bit payload used by the project.
  3. Transmit over SPI radio.The transmitter-specific nrftop configures an NRF24L01, writes the payload, and controls the CE/CSN transaction sequence.
  4. Receive and normalize.The vehicle-specific nrftop reads the radio payload and passes it through nrf_errorhandler.
  5. Drive the chassis.CONTROL_UNIT routes the command into one steering channel and four motor/ESC PWM outputs.

Known limitations and next proof

honest status

Recovery boundary

The report does not include the remote or vehicle XDC files, generated XADC/Clocking Wizard products, or the referenced byte_latch source. The recovered project therefore does not claim synthesis, bitstream generation, or a new hardware test.

Best next evidence

Recover or recreate the missing IP and constraints, review pin/electrical assumptions, elaborate and simulate the complete systems, then publish a repeatable hardware test for radio commands, steering, and motor outputs.
