ECD_PROJE: 3-bit ADC controller and VGA scope

A Basys3 design that participates in conversion rather than reading a finished ADC: it controls an external sample-and-hold/comparator path, assembles a 3-bit result with a SAR-style sequence, detects a trigger boundary, and draws samples on VGA.

Executive summary

what was built

Problem

Demonstrate a small end-to-end ADC system in which FPGA control, external analog decisions, and a live display operate as one path.

Implementation

An FSM drives sel[2:0] and hold, consumes comparator input din, then passes completed codes to trigger and VGA logic.

Result

The documented Vivado build produced a bitstream and the page records both the active digital path and the remaining generated-clock/endpoint constraints work.

Implementation flow

signal path
  1. Hold the analog sample.The external circuit captures the input; the FPGA asserts hold during conversion decisions.
  2. Select reference levels.The controller steps through bit0, bit1, and bit2 states while driving the reference MUX.
  3. Consume comparator decisions.din is sampled at each decision and assembled into the completed 3-bit output code.
  4. Detect a stable boundary.The trigger FSM watches completed codes for a low-to-high crossing before capture.
  5. Render the waveform.A double-buffered scope stores samples and draws a staircase trace on a 640×480 VGA frame.
