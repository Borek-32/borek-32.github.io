PROJECT 01

Done

MFCC-based FPGA spoken-digit recognizer

Area
FPGA / DSP / PCB design
Platform
Vivado / VHDL / MATLAB / LTSpice / KiCad
Status
Programmed FPGA; integrated PCB; live recognition tested

For EEE491, I built the fixed-point ADC, Hann window, FFT, MEL, LOGMEL, DCT, and SAD/L1 pipeline, its XSim/MATLAB checks, and the microphone/ADC PCB. The offline analysis gives 30/30; live recognition and reference recording/recall tests are also complete.

PROJECT 02

Done

FPGA 3-bit ADC and VGA oscilloscope

Area
Mixed-signal acquisition on FPGA
Platform
Basys 3 / VHDL / LTspice / breadboard
Status
Working breadboard ADC; four waveform shapes demonstrated

For EEE313, I built a three-bit ADC from discrete analog stages and used Basys 3 for conversion control, triggered capture, and a 640 × 480 VGA display. Laboratory tests show sine, square, triangle, and sawtooth conversion, with additional sine demonstrations at 500 Hz and 200 Hz.
